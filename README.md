# Home Credit LAP Qualification Voice Agent

## Project Overview
An AI-powered voice agent designed to qualify customers interested in a Loan Against Property (LAP) of up to ₹75 lakh.

## Key Features
- Customer greeting and identity verification
- Eligibility checks for property type and ownership
- Verification of original property documents
- Loan amount limit handling up to ₹75 lakh
- Occupation and bank-income verification
- Property market value and tenure collection
- Disqualification handling and loan-transfer routing
- Handoff of eligible customers to a senior loan expert

## Technology
- Retell AI for voice-agent creation and testing
- GitHub for version-controlled project documentation
